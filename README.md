# ChooseYourContent - 볼 콘텐츠 정하기

## 수정 사항
- 찜 목록 이름 설정과 콘텐츠 추가 및 콘텐츠 정보 추가 기능을 구현함.
- 기존의 콘텐츠 정보 입력 화면은 시청 콘텐츠 선별 기준 설정 폼의 형태로 사용되는 것이 더 자연스러워 보일 것 같다고 판단하여 이와 같이 변경함.
- 위와 같은 이유로 기존의 콘텐츠 제목 입력 부분을 찜 목록을 선택하는 화면으로 변경함.

## 인터렉션 시나리오
1. 정보 수집 및 활용 안내
- 기존과 동일하나 새롭게 구현된 찜 목록 작성 화면과 연결된다.

2. 찜 목록 이름 설정
- 행동, 이벤트: 이름을 적고 '목록 만들기' 를 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어있는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 '이름 수정하기' 와 '목록 작성' 버튼을 보여준다.
                '이름 수정하기' 를 누르면 '수정' 과 '취소' 버튼이 나타나고 이름을 수정할 수 있다.
                '수정' 을 누르면 이름이 변경되고 '취소'를 누르면 값이 유지된다.
                마찬가지로 '수정' 을 눌렀을 때 값이 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                '목록 작성' 을 누르면 콘텐츠 정보 작성 화면을 보여준다.

3. 콘텐츠 제목 입력
- 행동, 이벤트: 제목을 적고 '카테고리 선택하기' 를 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어있는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 '제목 수정' 버튼과 카테고리 선택 화면을 보여준다.
                '제목 수정' 을 누르면 '수정' 과 '취소' 버튼이 나타나고 이름을 수정할 수 있다.
                '수정' 을 누르면 이름이 변경되고 '취소'를 누르면 값이 유지된다.
                마찬가지로 '수정' 을 눌렀을 때 값이 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.

4. 분류 및 카테고리 선택
- 행동, 이벤트: 카테고리를 선택하고 '찜 목록에 콘텐츠 추가하기' 를 클릭한다.
- 조건: 추가 카테고리 선택하기를 선택했는가?
- 반응, 다음 상태: 선택했을 때만 카테고리 분류를 보여준다.

5. 콘텐츠 확인
- 행동, 이벤트: 찜한 콘텐츠의 제목, 분류, 카테고리 내용을 읽고 '수정하기' 또는 '감상할 콘텐츠 선택하기'를 클릭한다.
- 조건: 수정인가 완료인가?
- 반응, 다음 상태: 수정하면 제목 및 선택값을 유지하고 콘텐츠 정보 입력 화면을 다시 보여준다.
                완료하면 저장된 콘텐츠 정보를 보여주고 시청 콘텐츠 선별 기준 설정 화면로 이동한다.
6. 찜 목록 선택
- 행동, 이벤트: 현재 작성된 찜 목록 중 하나를 선택한다.
- 반응, 다음 상태: 현재 찜 목록 추가 기능이 구현되지 않아 선택에 변화를 줄 수는 없다.
                설정한 찜 목록의 이름이 반영된 radio input이 정상적으로 추가되는 것이 확인되었다.
                '카테고리 선택하기'를 누르면 다음 화면으로 이동한다.

## 테스트 결과
1. 기존의 연결이 찜 목록 설정으로 변경된 것이 확임됐다. '돌아가기'도 정상 작동한다.
2. console.log 등을 통해 찜 목록 이름과 수정한 값이 잘 저장되는 것을 확인했다.
    입력하지 않고 입력하거나 수정했을 때 오류 문구도 정상적으로 표시된다.
    수정을 취소했을 때 이름 값이 덮어씌워지지 않는다.
3. console.log 등을 통해 콘텐츠 제목과 수정한 값이 잘 저장되는 것을 확인했다.
    입력하지 않고 입력하거나 수정했을 때 오류 문구도 정상적으로 표시된다.
    수정을 취소했을 때 제목 값이 덮어씌워지지 않는다.
4. 복수 카테고리 선택이 잘 진행된다. 값을 선택하지 않을 수 있는 항목에는 값이 없는 것에도 반응하여 값을 출력한다.
5. 수정 화면과 다음 단계로 넘어가는 과정이 정상적으로 진행된다.
6. 정상적으로 다음 화면으로 넘어간다.
