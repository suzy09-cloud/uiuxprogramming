# ChooseYourContent - 볼 콘텐츠 정하기

## 10주차 네비게이션 UI와 정보 탐색 구현 기록

## 수정 사항
- 찜 목록 콘텐츠 추가 기능 및 삭제, 필터 기능을 구현함.
- 서비스에 적합한 주요 메뉴(5가지)를 추가함.
- 현재 메뉴를 시각적으로 구분하고 표시가 실제 위치를 표시하는 기능을 구현함.
- 모바일 메뉴 기능 구현
- 그 외 기타 오류 수정

## 인터렉션 시나리오
1. 정보 수집 및 활용 안내
- 이전과 동일.

2. 찜 목록 이름 설정
- 이용 단계는 이전과 동일, 목록 열기/닫기 기능 추가.
                목록을 열면 목록 관리 화면이 나온다.

3. 찜 목록 관리
- 행동, 이벤트: 저장된 찜한 콘텐츠의 제목, 분류, 카테고리 내용을 확인하고
                필터를 이용한 분류 별 내용 확인, 내용 삭제, 콘텐츠 추가하기 또는 감상할 콘텐츠를 선택할 수 있다.

- 반응, 다음 상태: 필터를 선택하면 전체 내용을 포함하여 '영화' 와 '시리즈' 
                로 분류하여 콘텐츠를 확인할 수 있다.
                콘텐츠 추가하기를 누르면 콘텐츠 추가 화면을 보여준다.
                각 항목의 삭제 버튼을 누르면 콘텐츠 정보가 삭제된다.
                감상할 콘텐츠 선택하기를 누르면 시청 콘텐츠 선별 기준 설정 화면로 이동한다.

3-1. 콘텐츠 제목 입력
- 이전과 동일.

3-2. 분류 및 카테고리 선택
- 이전과 동일

3-3. 콘텐츠 확인
- 행동, 이벤트: 찜한 콘텐츠의 제목, 분류, 카테고리 내용을 읽고 '수정하기' 또는 '확인하고 저장하기'를 클릭한다.
- 조건: 수정인가 완료인가?
- 반응, 다음 상태: 수정하면 제목 및 선택값을 유지하고 콘텐츠 정보 입력 화면을
                다시 보여준다.
                완료하면 저장된 콘텐츠 정보를 보여주고 찜 목록 관리 화면으로 돌아가거나 시청 콘텐츠 선별 기준 설정 화면로 이동한다.

4. 볼 컨텐츠 선택
- 이전과 동일

5. 환경설정
- 이전의 사용 준비 단계, 화면 테마 전환 또는 약관 동의
                여부를 확인할 수 있다.

## 테스트 결과
1. 사용 단계 메뉴가 해당 영역이나 화면으로 이동하도록 연결되었으며
    (해당 영역 또는 화면이 숨겨져 있을 경우는 나타났을 때만 표시됨),
    현재 위치에 해당하는 메뉴가 다른 메뉴와 시각적으로 구분됨. 또한 
    메뉴 이동, 새로고침, 브라우저 뒤로 가기 이후에도 현재 위치 표시가 실제 화면과 일치하는 것을 확인함.
2. 좁은 화면에서는 메뉴 열기·닫기 버튼을 통해 주요 메뉴를 펼치거나 접을 수
    있음. 현재 위치에 해당하는 메뉴가 표시되는 것 또한 정상 작동 되는 것이 확인됨.
3. 콘텐츠 목록에 전체를 포함한 '영화' , '시리즈' 필터 선택 시 버튼의 선택
    표시와 실제 목록 내용이 함께 변경되며 현재 표시되는 항목 수를 안내하고, 결과가 없으면 빈 화면 대신 안내 문구가 표시됨. 또한 전체 목록이 없는 경우와 선택한 조건에 맞는 결과만 없는 경우를 구분하여 안내하는 것을 확인함.
4. 그 외 기타 오류들이 수정됨.
