## 6주차 이벤트 처리와 동적 UI 구현 기록

### 1. 추가된 내용

- click, input, change 이벤트 추가
- 탭 UI 구현

### 2. 달라진 점

- 다크 모드 추가(버튼 문구로 현재 모드 확인 가능)
- 닉네임 설정 창 추가(길이 10(으)로 제한되는 것 표시됨)
- 정보 사용 동의 문구 및 시작 버튼 추가(동의에 체크해야 시작 버튼 활성화, 안내 문구 포함됨)
- 서비스의 기능을 설명하는 탭 3개 구현(선택된 탭 구분 가능, 해당 탭의 콘텐츠만 표시됨)

### 3. 확인한 화면 너비

1100px / 768px / 390px
(768px 이하에서 메뉴, 카드, 폼이 한 열로 구성되는 것을 확인함)
