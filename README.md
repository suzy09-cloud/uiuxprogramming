# ChooseYourContent - 볼 콘텐츠 정하기

## 사용자와 목표
- 사용자: OTT 이용자
- 목표: 사용하는 OTT에서 감상할 콘텐츠를 정해준다.

## 사용자의 흐름
1. 정보 수집 및 활용에 동의하고 '시작하기' 를 누른다.
2. 콘텐츠 제목을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 분류 및 카테고리를 선택한다.
4. 입력한 찜 목록 설정을 확인하고 수정하거나 완료한다.
5. 작성 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오
1. 정보 수집 및 활용 안내
- 행동, 이벤트: 기존 동의 박스 체크하고 '시작하기'를 클릭한다.
- 조건: 정보 수집 및 활용 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
                팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작화면에 남는다.
                '동의하고 작성 시작하기'를 누르면 찜 목록 작성 화면을 연다.
2. 콘텐츠 제목 입력
- 행동, 이벤트: 제목을 적고 '카테고리 선택' 을 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어있는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 카테고리 선택으로 이동한다.
3. 분류 및 카테고리 선택
- 행동, 이벤트: 카테고리를 선택하고 '찜 목록 확인하기' 를 클릭한다.
- 조건: 추가 카테고리 선택하기를 선택했는가?
- 반응, 다음 상태: 선택했을 때만 카테고리 분류를 보여준다.
4. 찜 목록 확인
- 행동, 이벤트: 찜한 콘텐츠의 제목, 분류, 카테고리 내용을 읽고 '수정하기' 또는 '작성 완료하기'를 클릭한다.
- 조건: 수정인가 완료인가?
- 반응, 다음 상태: 수정하면 기본값을 유지하고 분류 및 카테고리 선택으로 돌아간다.
                완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 작성하기'를 클릭한다.
- 반응, 다음 상태: 새 설정의 제목, 분류 및 카테고리, 진행 상태를 초기화하고 제목 입력부터 다시 시작한다.
                이미 확인한 정보 수집 및 활용 동의와 다른 기능을 유지한다.
