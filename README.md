## 4주차 반응형 수정 기록

### 1. 확인된 문제

- 작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁게 보임
- 웹사이트 배경 색상을 변경하고 싶음(색이 너무 진함)


### 2. 수정한 내용

- viewport 메타태그 추가
- 콘텐츠에 width와 max-width 함께 사용
- .feature-list를 반응형 Grid로 변경
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성

- background-color 수정

### 3. 달라진 점

- 확대하지 않아도 구성 요소를 보고 읽을 수 있음
- 웹사이트 배경 색이 연해짐

### 4. 확인한 화면 너비
